# С чего начать

## Посмотреть сайт

Открой `cobalt.html` в браузере. Это один файл со всей моделью.

## Загрузить на GitHub

1. Создай репозиторий, например `cobalt-3d`.
2. Открой его и выбери **Add file → Upload files**.
3. Перетащи содержимое папки из архива. Загружай файлы и папки,
   а не сам ZIP и не внешнюю папку `cobalt-3d` целиком.
4. Проверь, что `index.html`, `README.md`, папки `assets` и `.github`
   оказались в корне репозитория.
5. Нажми **Commit changes**. Основная ветка должна называться `main`.
6. В **Settings → Pages** выбери источник **GitHub Actions**.
7. В **Actions** открой `Check and publish Cobalt 3D`.
   При необходимости нажми **Run workflow** для ветки `main`.
8. Дождись успешной проверки и публикации. Ссылка будет в **Settings → Pages**.

GitHub Pages из публичного репозитория делает опубликованный сайт доступным
по ссылке. Эта инструкция не меняет доступ к прежней опубликованной версии.

Подробности запуска и редактирования находятся в `README.md`.
