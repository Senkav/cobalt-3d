# Cobalt 3D

Интерактивный учебный атлас Chevrolet Cobalt для студентов-автомехаников.
Выбираешь деталь на модели или в списке и читаешь её назначение, связи,
влияние на работу машины, способы проверки и ремонта.

Проект работает на обычном статическом хостинге. Серверная часть,
платные API и установка npm-пакетов не нужны.

## Что есть на сайте

- 94 учебных узла в единой 3D-сцене.
- Виды автомобиля, моторного отсека, внутреннего устройства двигателя,
  днища и салона.
- Вращение, приближение, открытие капота и дверей, прозрачность кузова.
- Поиск, выбор системы, связи деталей и сохранённые детали.
- Анимация четырёх тактов с паузой и выбором положения коленвала.
- Учебный маршрут: 5 разделов, 22 ключевых узла.
- Поиск деталей на модели: 10 вопросов за попытку из банка 40 деталей.
- 8 диагностических ситуаций, 32 решения с объяснениями.
- Разборка двигателя, потоки жидкостей и режим защиты курсовой.
- Крупный текст, светлая и тёмная темы, помощь и чтение на весь экран.
- Озвучивание текста, если браузер поддерживает синтез речи.
- Сохранение прогресса в браузере и скачивание результатов занятий в TXT.

## Быстро открыть

**Без сервера:** открой `cobalt.html` в браузере с поддержкой WebGL.
Внутри уже находятся код, стили, библиотеки и сжатая модель.
На телефоне файловый просмотрщик может не запускать JavaScript:
в таком случае открой опубликованный сайт в браузере.

**Для разработки:** из корня проекта выполни:

```bash
python3 -m http.server 8000
```

Открой <http://localhost:8000>. На Windows можно использовать
`py -m http.server 8000` или `python -m http.server 8000`.

Основная версия для хостинга — `index.html`. Ей нужна папка `assets` рядом.
Просто открыть этот файл через `file://` недостаточно для загрузки GLB.

## Опубликовать на GitHub Pages

1. Создай репозиторий с основной веткой `main`.
2. Загрузи **содержимое** распакованной папки, включая `.github`.
   Файл `index.html` должен находиться в корне репозитория.
3. Открой **Settings → Pages → Build and deployment**.
4. В поле **Source** выбери **GitHub Actions**.
5. Во вкладке **Actions** запусти `Check and publish Cobalt 3D`
   через **Run workflow**, если публикация ещё не запустилась.

После успешного выполнения ссылка появится в **Settings → Pages**.
Следующие изменения в `main` будут проверяться и публиковаться автоматически.
Для GitHub Free публикация Pages доступна из публичного репозитория.

Подробнее: [инструкция публикации](docs/PUBLISHING.md)
и [официальная документация GitHub](https://docs.github.com/en/pages/getting-started-with-github-pages/using-custom-workflows-with-github-pages).

## Проверить проект

Нужны Python 3.10+ и Node.js 22 или новее. Зависимости устанавливать не нужно.

```bash
python3 scripts/check-project.py
node scripts/check-js.cjs
node scripts/check-model.cjs
python3 scripts/build-standalone.py --check
```

Проверки находят отсутствующие файлы, повторяющиеся HTML ID,
ошибки синтаксиса JavaScript, повреждённый GLB и несоответствие одиночного
HTML исходникам. Проверка 3D создаёт геометрию без WebGL-рендера,
выбирает все 94 узла и проверяет движение механизма.
Отображение, контраст во всех состояниях и удобство на конкретном телефоне
нужно проверять в браузере вручную.

## Внести изменения

Редактируй `index.html` и файлы в `assets`. Затем обнови одиночный HTML:

```bash
python3 scripts/build-standalone.py
```

Добавь изменённый `cobalt.html` в тот же коммит.
Проверка в GitHub Actions обнаружит, если он устарел.

[Порядок загрузки и структура кода](docs/ARCHITECTURE.md).

## Какой автомобиль показан

Учебный профиль: Cobalt II с бензиновым B15D2 1,5 л, передним приводом
и пятиступенчатой механической коробкой. Привод ГРМ цепной.
Профиль и ссылки на документы находятся в [технических источниках](docs/SOURCES.md).

Кузов и салон основаны на импортированной модели. Механические узлы
построены для объяснения устройства. Их форма и положение приблизительные.
Проект не является заводской CAD-моделью или ремонтным руководством.

## Сохранение данных

Прогресс, закладки, результаты и настройки чтения сохраняются в `localStorage`.
Они относятся к текущему браузеру и адресу сайта. Внешняя база данных
не используется. Ссылки на видео, документы и синтез речи могут требовать сети
или поддержки браузера, хотя сама модель и учебные тексты находятся локально.
